Fase 1: Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut.

1. Shared Hosting

Layanan hosting yang digunakan bersama oleh banyak pengguna dalam satu server. Biayanya lebih murah, tetapi sumber daya server harus dibagi dengan pengguna lain.

2. Dedicated Server

Layanan server yang digunakan khusus oleh satu pengguna. Semua sumber daya server tersedia untuk pengguna tersebut, tetapi biayanya lebih mahal.

3. Amazon Lightsail

Layanan cloud dari AWS yang memudahkan pengguna membuat dan mengelola server virtual dengan harga yang relatif terjangkau dan biaya yang lebih mudah diperkirakan.

4. Amazon EC2

Layanan AWS yang menyediakan server virtual dengan pengaturan yang lebih fleksibel. Pengguna dapat menentukan kapasitas dan konfigurasi server sesuai kebutuhan.
